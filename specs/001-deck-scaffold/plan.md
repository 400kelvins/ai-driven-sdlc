# Implementation Plan: Deck Scaffold with Arrow-Key Navigation

**Branch**: `001-deck-scaffold` | **Date**: 2026-10-12 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `specs/001-deck-scaffold/spec.md`

## Summary

Stand up a Slidev deck at the repo root: `slides.md` entry with headmatter, seven section files in
`pages/` pulled in with `src:`, Slidev's built-in arrow-key navigation, static build to `dist/`,
then an early Vercel preview deploy with a log check.

## Technical Context

**Language/Version**: Markdown + Vue SFC (Slidev), Node 22.x (engines)
**Primary Dependencies**: `@slidev/cli@53.0.0`, `@slidev/theme-default@0.25.0` (pinned)
**Storage**: N/A
**Testing**: Playwright smoke test via Slidev dev server (arrow-key navigation, 7 section titles);
`npm run build` as build gate
**Target Platform**: Chromium-based browser on presenter laptop; Vercel static hosting
**Project Type**: Static web app (slide deck)
**Performance Goals**: Deck opens locally in < 2 min from fresh checkout (SC-001)
**Constraints**: Offline at runtime (no CDN fonts); one file per section
**Scale/Scope**: 7 sections, 1 placeholder slide each
